# leetcode-dsa-problems

This repository contains my LeetCode problem-solving journey.

Instead of storing only final optimized solutions, I document:
- Initial approaches
- Mistakes and failed logic
- Optimization attempts
- Final accepted solutions
- Key learnings from each problem

The goal is to improve problem-solving skills systematically and track thought progression over time.

Topics Covered:
- Arrays
- Strings
- Hashing
- Sliding Window
- Dynamic Programming
- Graphs
- Trees
- Backtracking
